# Security Policy

Baseline handles sensitive health data, so security and privacy reports are taken seriously.

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Instead, report them privately through GitHub:

1. Go to the repository's [**Security** tab](https://github.com/Om-Kamath/baseline/security).
2. Click **Report a vulnerability**.

Please include what you found, how to reproduce it, and the impact you think it has. You can expect an initial response within a week.

## What's in scope

- Anything that could expose a user's health data, including to other apps on the device
- Code that sends data off the device unexpectedly
- Flaws that let data be read or changed without the user's permission

## Supported versions

Only the latest version on the `main` branch is supported.
